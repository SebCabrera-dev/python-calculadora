# Calculadora Avanzada en Python

Una aplicación de consola desarrollada en Python que permite realizar operaciones matemáticas simples y compuestas con soporte para múltiples números, herramientas estadísticas y un historial de sesión.

## 🚀 Características
- **Operaciones Múltiples:** Suma, resta y multiplicación de listas de números ($N$ elementos).
- **Operaciones Especiales:** Potenciación, raíz cuadrada y cálculo de porcentajes.
- **Herramientas Estadísticas:** Cálculo de promedio, valor máximo y valor mínimo sobre conjuntos de datos.
- **Historial de Operaciones:** Registro en memoria para consultar los resultados durante la sesión.
- **Robustez y Control de Errores:** Validación de entradas no numéricas (`try/except`) y prevención de división por cero.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Python 3.14
- **Módulos:** `math`
- **Control de Versiones:** Git & GitHub
